Associer mon compte Discord ou Twitch

Cette association sert à faire reconnaître ton compte Discord ou Twitch par Jade. Elle n'est pas nécessaire pour activer la mémoire de l'application mobile, déjà associée au profil privé du propriétaire lorsque la mémoire est activée.

  1. Sur Discord ou Twitch, depuis le compte à associer (pas dans cette application mobile) :

    Discord (MP ou serveur) : la mémoire s'active automatiquement dès qu'un compte identifié interagit avec Jade. Envoie seulement !jade-memoire identite à Jade.

    Twitch (chat) : envoie d'abord !jade-memoire activer, puis !jade-memoire identite à Jade.

    Recopie l'identifiant numérique renvoyé par Jade, pas le pseudo du compte.

  2. Dans cette application mobile :

    Choisis le service du compte à associer et saisis son identifiant numérique.

    Le code de confirmation expire au bout de 5 minutes. Il est à usage unique et lié à ce compte. L'association, une fois confirmée, n'expire pas.

  3. Retour sur Discord ou Twitch, depuis ce même compte :

    Envoie à Jade la commande !jade-memoire confirmer [code généré] fournie par l'application mobile, avant l'expiration du code. Les souvenirs condensés des comptes liés peuvent être retrouvés sur mobile, au micro PC et en MP Discord. Les salons publics et les historiques complets restent isolés.

Depuis Discord ou Twitch, !jade-memoire delier sépare les comptes sans effacer leurs souvenirs ; !jade-memoire oublier efface les données du compte concerné.
