# Portrait Discord de Jade

`jade-r21-discord.png` est un portrait dérivé du
[maître graphique r21](../../jade-modeling/assets/live2d/r21_professional_art/master_v4_assets_v1/Jade_r21_master_v3_canvas_3840x4160.png).
Il a été préparé avec ImageGen pour cadrer tête et épaules, puis contrôlé
visuellement. Il conserve l'apparence r21 ; ce n'est pas un export natif de
Cubism ni une garantie de pixels identiques au maître. Les sources originales
restent intactes.

La mise à jour de la photo du **bot** Discord a réussi et a été vérifiée par
relecture de son profil. L'ancien portrait et le reçu technique restent dans
l'espace privé local ; aucun jeton ou identifiant de compte n'est publié ici.
Cette photo ne change pas le modèle animé du MVP, qui demeure r20.
