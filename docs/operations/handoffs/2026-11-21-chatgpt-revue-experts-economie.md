# Passation : revue des six améliorations économiques et du P0 Discord MP

- **Date :** 21 novembre 2026. **Branche :** `review/jade-economy-expert-pass-20261121`, [PR #35](https://github.com/goldaj/jade-vtuber/pull/35).
- **Méthode :** lecture du code et des politiques du projet, revue selon les perspectives PO/architecte, ingénieur backend/SQLite, confidentialité, Discord, budget API et audio mobile. Il s'agit d'une revue multi-disciplinaire ChatGPT, **pas** d'une validation prétendument effectuée par plusieurs experts humains indépendants.
- **Défauts identifiés et corrigés :** réarmement d'une initiative par toute conversation entre humains ; fuite potentielle des souvenirs individuels via prompts publics ; type autobiographique `core_self` réattribué à la mémoire d'un tiers ; personnalité de Jade déduite des goûts d'autrui ; curation payante sur doublons/banalités ; absence de fallback pour un MP Discord connu mais absent du cache ; message non remis stocké comme s'il avait été livré ; sortie terminal de textes de MP.
- **Décisions préservées :** salut spontané possible au premier événement humain sans parole, initiatives non plafonnées numériquement et activées par défaut ; un seul contact avant réponse réelle, pas de polling ; curation groupée et Core autonomes ; historique L1 7 jours, reprise 24h non destructive, L2 365 jours et Core sans purge ; streaming mobile existant sans modèle Realtime supplémentaire.
- **QA :** tests de non-régression ajoutés pour réponses humaines pertinentes, confidentialité multi-canaux, Core externes, déduplication/banalités, cache privé DM et erreurs de livraison. Les workflows doivent être vérifiés sur le dernier commit de la PR (Linux/Windows, contrôle documentaire, scan de secrets). Ne déclarer aucune recette réelle PC/Android/Discord réussie par déduction.
- **Restant / risques :** DEV-019 P0 reste ouvert jusqu'à recette MP réelle sur plusieurs identités et refus de permission, REC-002 et REC-005 restent séparées ; état d'attente d'initiative non persistant à travers redémarrage, coûts USD estimatifs, classification sociale LLM payante facultative et voix Android à recetter. La recherche de l'historique est lexicale plutôt que sémantique ; une session SQLite longue reste à observer en charge.
- **Conformité de process :** aucune modification de `main`, aucun secret, aucune API payante invoquée. `develop` n'est intégré qu'après CI verte, revue de diff et vérification du SHA.
