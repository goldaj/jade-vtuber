## Éléments à conserver

Le nouveau chemin actif utilise OpenAI pour STT/TTS ; les chaînes ElevenLabs encore présentes dans le fichier de compatibilité `credentials.py` ne sont pas un moteur vocal actif. Les tests d’absence de dépendance vocale alternative passent. Le chargement privé et les profils non secrets permettent une migration progressive ; ne jamais copier les valeurs du coffre dans la documentation.

Les anciens avertissements sur les identifiants historiques restent valables. Le scanner basique courant passe, mais ne certifie ni l’historique, ni les binaires, ni les droits. Ne pas confondre intégration privée, première exploitation et publication de sources.
