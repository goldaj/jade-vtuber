**Statut réel :** [`CURRENT_PUBLIC_STATUS.md`](CURRENT_PUBLIC_STATUS.md). Le dépôt `goldaj/jade-vtuber` est déjà **public** au 16 novembre 2026. Les anciens plans de migration ou le [snapshot des gates du 28 octobre](04-RELEASE-GATES.json) restent des artefacts historiques ; ils ne décrivent pas automatiquement la situation publique actuelle.

Le modèle et les licences doivent être examinés selon [`jade-modeling/PROVENANCE.md`](../../jade-modeling/PROVENANCE.md).
